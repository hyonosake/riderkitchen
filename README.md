# Rider Kitchen

Локальная версия сайта кейтеринг-сервиса (оригинал:
https://riderkitchen.ru/): перенос контента, фиксы вёрстки, разбивка
на компоненты, новые фичи. План работ — в [`docs/PLAN.md`](docs/PLAN.md),
найденные на оригинале баги — в [`docs/BUGS.md`](docs/BUGS.md).

## Запуск

```bash
npm install
npm run dev
```

Другие команды: `npm run build`, `npm run preview`, `npm run lint`.

Стек: React + TypeScript + Vite.
